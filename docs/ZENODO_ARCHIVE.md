# Zenodo archive layout

The companion Zenodo review record is split into independently downloadable
archives. Extract `mcnh_code_snapshot.zip` first, then overlay whichever large
products are required:

1. `mcnh_code_snapshot.zip`: the GitHub release at the cited commit.
2. `mcnh_model_ready_inputs.zip`: blinded NeuralHydrology inputs, basin lists,
   and forcing-only anchors.
3. `mcnh_source_inputs.zip`: source tables and arrays used to build the
   model-ready inputs.
4. `mcnh_initial_runs_and_mclstm.zip`: initial epoch-30 runs and descriptive
   MC-LSTM products.
5. `mcnh_selected_adaptive_checkpoints.zip`: selected adaptive checkpoints,
   optimizer states, scalers, configurations, and validation products.
6. `mcnh_frozen_predictions.zip`: frozen target predictions for the four
   closure-admitted architectures.
7. `mcnh_zero_pet_interventions.zip`: prespecified zero-PET intervention
   trajectories, fingerprints, and receipts.
8. `mcnh_dhbv_float64_replays.zip`: zero-PET and climatological-PET dHBV
   float64 replays.
9. `mcnh_pet_climatology_interventions.zip`: climatological-PET sensitivity
   trajectories, fingerprints, and receipts.
10. `mcnh_full_process_trajectories.zip`: the full gauge-level process table
    omitted from GitHub.

`ZENODO_MANIFEST.csv` records each archive's byte size and SHA-256 digest.
`ZENODO_CONTENTS.csv` records every archived file and its digest. Failed MCP
runs, manuscript text, document-building code, and rendered publication figures
are excluded.

The archive set is generated by `workflow/build_zenodo_archives.py`. For
example:

```bash
python workflow/build_zenodo_archives.py \
  --source-project /path/to/frozen/source/project \
  --output /path/to/zenodo_release
```
